# Fruit Puzzle 🍇🍊🍓

A fun and engaging match-3 puzzle game where players match fruits to score points and progress through increasingly challenging levels. Built with TypeScript and deployed live on Render.

## 🎮 About

Fruit Puzzle is a casual match-3 game inspired by classic titles like Candy Crush. Players swap adjacent fruits to create matches of three or more, clearing them from the board to earn points and advance through levels. The game focuses on simple, addictive gameplay with clean visuals and smooth interactions.

## 🚀 Getting Started

1. Clone the repository
   ```
   git clone https://github.com/SumanSaini08/fruit-puzzle.git
   ```
2. Navigate into the project folder
   ```
   cd fruit-puzzle
   ```
3. Install dependencies
   ```
   npm install
   ```
4. Run the development server
   ```
   npm run dev
   ```
5. Open the app in your browser at the local URL shown in the terminal

## 🕹️ How to Play
<img width="1346" height="642" alt="game" src="https://github.com/user-attachments/assets/443f83a6-0d10-457a-9ccc-94910aa8f1fc" />

1. Swap two adjacent fruits to form a line of three or more matching fruits
2. Matched fruits are cleared from the board and points are added to your score
3. Keep matching to clear levels and beat your high score
